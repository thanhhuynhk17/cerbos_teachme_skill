Cerbos Cheat Sheet

Tóm tắt từ các bài học. Mỗi mục có link về nguồn gốc.

Mô hình request

  • principal: id, roles[], attr{}
  • resource: kind, id, attr{}
  • actions[]: chuỗi tuỳ đặt, vd view:public
  • Kết quả: mỗi action được EFFECT_ALLOW hoặc EFFECT_DENY
  • Mặc định deny. Không rule nào khớp thì là DENY
  • App tự lấy attr từ DB và gửi kèm. Cerbos không đọc DB của anh

Nguồn: quickstart · Bài 0001

Cerbos quyết định thế nào

  1. Tìm resource policy có resource = kind. Không có thì DENY
  2. Tính derived roles của principal
  3. Rule khớp khi: action ∈ actions (hoặc '*'), principal có role ∈ roles hoặc derived role ∈ derivedRoles, và condition đúng
  4. Có ALLOW khớp thì ALLOW. Không có rule nào khớp thì DENY. Cùng một role khớp cả DENY lẫn ALLOW thì DENY thắng

Derived roles

---
apiVersion: "api.cerbos.dev/v1"
derivedRoles:
  name: common_roles          # tên để import
  definitions:
    - name: owner
      parentRoles: ["user"]   # phải có 1 role này
      condition:
        match:
          expr: request.resource.attr.owner == request.principal.id

Derived role = role tĩnh (RBAC) + điều kiện (ABAC), tính lúc request. docs

Resource policy

---
apiVersion: api.cerbos.dev/v1
resourcePolicy:
  version: "default"
  importDerivedRoles: [common_roles]
  resource: "album:object"     # = resource.kind
  rules:
    - actions: ['*']           # mọi action
      effect: EFFECT_ALLOW
      derivedRoles: [owner]
    - actions: ['view:public']
      effect: EFFECT_ALLOW
      roles: [user]            # role tĩnh
      condition:
        match:
          expr: request.resource.attr.public == true

Python SDK

from cerbos.sdk.client import CerbosClient
from cerbos.sdk.model import (Principal, Resource,
    ResourceAction, ResourceList)

p = Principal("bugs_bunny", roles=["user"],
              attr={"beta_tester": True})
r = Resource("BUGS001", "album:object",
             attr={"owner": "bugs_bunny", "public": False})

with CerbosClient(host="http://localhost:3592") as c:
    # 1 resource, 1 action -> bool
    c.is_allowed("comment", p, r)

    # nhiều resource × nhiều action, 1 lần gọi
    resp = c.check_resources(
        principal=p,
        resources=ResourceList(resources=[
            ResourceAction(r, actions=["view:public", "comment"]),
        ]),
    )
    resp.raise_if_failed()
    resp.get_resource("BUGS001").is_allowed("comment")
    resp.to_dict()   # JSON thô

storage · admin_api · Bài 0002

Bẫy đã gặp

  • Derived role không được cấp nếu principal thiếu parentRoles, dù điều kiện đúng
  • Rule có roles: [user] mà không có điều kiện thì mở cho mọi user
  • Verify ngay sau khi sửa policy có thể vẫn ra kết quả cũ. Đợi khoảng 3 giây (driver disk)
  • DELETE /admin/policy đã deprecated và chỉ disable; muốn xoá hẳn thì dùng /admin/policy/delete
